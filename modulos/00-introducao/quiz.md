# Quiz · Módulo 00 · Introdução

Responde de cabeça antes de abrires cada resposta. Se errares mais de duas, relê o [módulo](README.md) antes de avançar.

### 1. O que é um sistema de controlo de versões?

- A) Um programa que faz cópias de segurança do computador inteiro
- B) Um sistema que regista a história de um projeto: o que mudou, quem mudou, quando e porquê
- C) Um site para partilhar ficheiros
- D) Um editor de código

<details>
<summary>Ver resposta</summary>

**B.** O controlo de versões guarda "fotografias" do projeto ao longo do tempo, com autor, data e uma mensagem a explicar o motivo.

</details>

### 2. Qual destas frases está correta?

- A) O Git é um site e o GitHub é um programa
- B) O Git e o GitHub são a mesma coisa
- C) O Git é um programa que corre no teu computador e o GitHub é um serviço que aloja repositórios Git na internet
- D) O GitHub é a versão paga do Git

<details>
<summary>Ver resposta</summary>

**C.** O Git é a ferramenta, o GitHub é um sítio onde se guardam e partilham repositórios Git.

</details>

### 3. Estás num avião, sem internet. O que consegues fazer com o Git?

- A) Nada, o Git precisa de ligação ao GitHub
- B) Só ver ficheiros, sem gravar nada
- C) Fazer commits e consultar o histórico completo
- D) Enviar commits para o GitHub

<details>
<summary>Ver resposta</summary>

**C.** O histórico completo fica na tua máquina. Só precisas de internet para trocar commits com um remoto (`push`, `pull`, `clone`).

</details>

### 4. O que é um commit?

- A) Uma "fotografia" do projeto num dado momento
- B) Uma cópia do repositório na internet
- C) Uma linha de trabalho paralela
- D) Um pedido de revisão

<details>
<summary>Ver resposta</summary>

**A.** A opção B descreve um remoto, a C uma branch e a D um pull request.

</details>

### 5. Que operação envia os teus commits do computador para o GitHub?

- A) `pull`
- B) `clone`
- C) `merge`
- D) `push`

<details>
<summary>Ver resposta</summary>

**D.** `push` envia, `pull` traz, `clone` descarrega uma cópia completa pela primeira vez.

</details>

### 6. Qual destas é uma alternativa ao GitHub?

- A) GitLab
- B) VS Code
- C) Linux
- D) Markdown

<details>
<summary>Ver resposta</summary>

**A.** O GitLab e o Bitbucket são serviços do mesmo tipo. Todos usam Git por baixo.

</details>
