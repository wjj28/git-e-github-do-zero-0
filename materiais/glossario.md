# Glossário

Os termos de Git e GitHub usam-se quase sempre em inglês, mesmo em equipas que falam português. Aqui fica o significado de cada um.

| Termo | Significado |
|-------|-------------|
| **Alias** | Atalho definido por ti para um comando Git |
| **Amend** | Corrigir o último commit, substituindo-o por um novo |
| **Branch** (ramo) | Linha de trabalho independente dentro do repositório |
| **Cherry-pick** | Copiar um commit específico para a branch atual |
| **Clone** | Cópia completa de um repositório remoto no teu computador |
| **Commit** | Registo ("fotografia") do estado do projeto, com autor, data e mensagem |
| **Conflito** (conflict) | Situação em que o Git não consegue juntar alterações sozinho, porque tocam nas mesmas linhas |
| **Diff** | Diferença entre duas versões, linha a linha |
| **Fast-forward** | Merge em que a branch apenas avança, sem criar commit de merge |
| **Fetch** | Descarregar novidades do remoto sem as integrar |
| **Fork** | Cópia de um repositório de outra pessoa na tua conta do GitHub |
| **Hash** (SHA) | Identificador único de um commit, por exemplo `a1b2c3d` |
| **HEAD** | Apontador para o commit onde estás neste momento |
| **Issue** | Registo de uma tarefa, erro ou ideia no GitHub |
| **Main** | Nome habitual da branch principal (antigamente `master`) |
| **Merge** | Juntar o trabalho de uma branch noutra |
| **Origin** | Nome por convenção do remoto principal |
| **Pull** | Descarregar e integrar novidades do remoto (`fetch` + `merge`) |
| **Pull request** (PR) | Pedido para integrar uma branch noutra, com espaço para revisão |
| **Push** | Enviar commits locais para o remoto |
| **README** | Ficheiro de apresentação do repositório |
| **Rebase** | Reaplicar commits em cima de outra base, reescrevendo o histórico |
| **Reflog** | Registo de todos os movimentos do `HEAD` |
| **Release** | Versão publicada no GitHub, associada a uma tag |
| **Remote** (remoto) | Cópia do repositório alojada noutro sítio |
| **Repositório** (repo) | Pasta do projeto com todo o seu histórico |
| **Revert** | Criar um commit que anula as alterações de outro |
| **Review** (revisão) | Leitura e comentário das alterações de um PR por outra pessoa |
| **SSH** | Protocolo de ligação segura, usado para autenticação com chaves |
| **Staging area** (área de preparação, index) | Onde ficam as alterações escolhidas para o próximo commit |
| **Stash** | Arrumar temporariamente alterações que ainda não queres gravar |
| **Tag** | Nome fixo dado a um commit, normalmente para marcar versões |
| **Token** | Código que substitui a palavra-passe na autenticação |
| **Tracked / untracked** | Ficheiro que o Git acompanha / que o Git ainda não acompanha |
| **Upstream** | O repositório original de onde fizeste fork. Também: a branch remota ligada à tua branch local |
| **Working directory** (pasta de trabalho) | Os ficheiros do projeto tal como estão no disco |
| **`.gitignore`** | Ficheiro com a lista do que o Git deve ignorar |
